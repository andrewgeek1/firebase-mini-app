1. VISUAL STUDIO CODE

Скачать:
https://code.visualstudio.com/download

Выбрать:
Windows -> User Installer -> x64

При установке рекомендуется включить:
- Add to PATH
- Add "Open with Code" action
- Register Code as an editor

После установки открыть VS Code.

2. GIT

Скачать:
https://git-scm.com/install/windows

Выбрать версию для Windows x64.

При установке:
- на этапе выбора редактора можно выбрать Visual Studio Code;
- остальные параметры можно оставить по умолчанию.

Проверка установки:

Открыть Пуск -> PowerShell и выполнить:

git --version

Если появилась версия Git, например:
git version 2.x.x

значит установка прошла успешно.

3. NODE.JS

Скачать:
https://nodejs.org/en/download

Выбрать:
LTS -> Windows Installer -> x64

Установить с настройками по умолчанию.

ВАЖНО:
npm устанавливается автоматически вместе с Node.js. Отдельно npm скачивать не нужно.

После установки открыть PowerShell и проверить:

node -v

Затем:

npm -v

Обе команды должны показать версии.

Node.js будет использоваться для бэкенда и запуска JavaScript вне браузера.
npm нужен для установки библиотек и зависимостей проекта.

Пример команды, которую будем использовать позже:

npm install express

4. MYSQL

Скачать:
https://dev.mysql.com/downloads/mysql/

Также можно использовать MySQL Installer:
https://dev.mysql.com/downloads/installer/

Для Windows удобно использовать MySQL Installer и выбрать вариант Developer Default.

В составе установки нужны:
- MySQL Server
- MySQL Workbench

Во время настройки MySQL Server:

Выбрать:
Standalone MySQL Server

Порт оставить:
3306

Во время создания пользователя root задать пароль.

Например:
Root12345!

ВАЖНО:
Пароль нужно запомнить или сохранить. Он понадобится для подключения к базе данных.

5. MYSQL WORKBENCH

Если Workbench был установлен через MySQL Installer с вариантом Developer Default, отдельно устанавливать его обычно не требуется.

Если его нет, скачать:
https://dev.mysql.com/downloads/workbench/

Workbench нужен для:
- создания базы данных;
- создания таблиц;
- выполнения SQL-запросов;
- настройки связей между таблицами;
- создания ER-диаграммы.

После установки запустить MySQL Workbench.

Найти подключение:
Local instance MySQL80

Открыть его и ввести пароль root, который был задан при установке.

Для проверки можно выполнить:

SELECT VERSION();

Если появилась версия MySQL, соединение работает.

13. УСТАНОВКА ФРЕЙМВОРКОВ И БИБЛИОТЕК

Для этого задания удобно использовать:
- Express — фреймворк для бэкенда на Node.js;
- Bootstrap — библиотека для адаптивного интерфейса;
- mysql2 — библиотека для подключения Node.js к MySQL;
- bcrypt — библиотека для безопасного хранения паролей;

- cors — для настройки взаимодействия фронтенда и бэкенда.

Фреймворки и библиотеки устанавливаются не отдельными программами Windows, а через npm внутри папки проекта.

15. СОЗДАНИЕ NODE.JS ПРОЕКТА

В терминале выполнить:

npm init -y

После этого в папке проекта появится файл:

package.json

Он содержит информацию о проекте и список его зависимостей.

16. УСТАНОВКА EXPRESS

В терминале выполнить:

npm install express

После установки появятся:
- папка node_modules;
- файл package-lock.json;
- зависимость express в package.json.

Express будет использоваться для создания серверной части приложения.

17. УСТАНОВКА ПОДКЛЮЧЕНИЯ К MYSQL

Выполнить:

npm install mysql2

Библиотека mysql2 позволит бэкенду Node.js подключаться к базе данных MySQL.

18. УСТАНОВКА БИБЛИОТЕКИ ДЛЯ ПАРОЛЕЙ

Выполнить:

npm install bcrypt

bcrypt нужен для хеширования паролей пользователей перед сохранением их в базе данных.

19. УСТАНОВКА СЕССИЙ

Выполнить:

npm install express-session

express-session понадобится для авторизации пользователей и хранения информации о текущей сессии.

20. УСТАНОВКА CORS

Выполнить:

npm install cors

cors используется для настройки запросов между клиентской и серверной частями приложения, если фронтенд и бэкенд работают на разных адресах или портах.

21. УСТАНОВКА BOOTSTRAP

Bootstrap можно подключить через npm.

Выполнить:

npm install bootstrap

Bootstrap поможет создать адаптивный интерфейс, кнопки, формы, карточки, таблицы и другие элементы интерфейса.

Для задания это особенно удобно, поскольку необходимо предусмотреть корректное отображение страниц на смартфоне с разрешением 390x844 px.

22. УСТАНОВКА JAVASCRIPT-ПАКЕТОВ ДЛЯ РАЗРАБОТКИ

При необходимости можно установить nodemon:

npm install --save-dev nodemon

nodemon автоматически перезапускает сервер Node.js после изменения файлов.

После установки в package.json можно добавить команду запуска:

"scripts": {
    "start": "node server.js",
    "dev": "nodemon server.js"
}

После этого сервер в режиме разработки можно запускать командой:

npm run dev

Обычный запуск:

npm start

23. ИТОГОВАЯ КОМАНДА ДЛЯ УСТАНОВКИ ОСНОВНЫХ ЗАВИСИМОСТЕЙ

Если Node.js уже установлен, а папка проекта создана, основные зависимости можно установить одной командой:

npm install express mysql2 bcrypt express-session cors bootstrap

Для разработки дополнительно:

npm install --save-dev nodemon

24. ПРОВЕРКА УСТАНОВКИ ФРЕЙМВОРКОВ

После установки проверить содержимое файла:

package.json

В разделе dependencies должны находиться установленные пакеты, например:

mysql2
bcrypt
express-session
cors

В папке проекта также должна появиться:

.gitignore

node_modules/

27. УСТАНОВКА PYTHON

Скачать Python:
https://www.python.org/downloads/

Для Windows можно использовать официальный Python Install Manager или установщик Python с python.org.

После установки открыть PowerShell и проверить:

python --version

Также можно проверить:

py --version

Проверить pip:

python -m pip --version

Для отдельных Python-проектов рекомендуется создавать виртуальное окружение:

python -m venv .venv

Активация в PowerShell:

.venv\Scripts\Activate.ps1

После активации в начале строки терминала появится:

(.venv)

Python нужен только для тех проектов, где бэкенд или отдельные инструменты будут написаны на Python.

28. УСТАНОВКА VUE.JS

Vue не нужно устанавливать как отдельную программу Windows.

Для создания Vue-проекта нужен Node.js и npm.

Официальная документация Vue:
https://vuejs.org/guide/quick-start

Открыть PowerShell или терминал VS Code.

Перейти в папку, где будут храниться проекты, например:

cd C:\Projects

Создать новый Vue-проект:

npm create vue@latest

После команды Vue задаст вопросы.

Для обычного учебного проекта можно выбрать:

Project name:
qwe-vue

Add TypeScript?
No

Add JSX Support?
No

Add Vue Router?
Yes, если проект будет состоять из нескольких страниц/маршрутов.

Add Pinia?
No

Add Vitest?
No

Add End-to-End Testing?
No

Add ESLint?
Yes

Add Prettier?
Yes

После создания проекта:

cd qwe-vue

Установить зависимости:

npm install

Запустить проект:

npm run dev

В терминале появится локальный адрес, например:

http://localhost:5173/

Открыть этот адрес в браузере.

ВАЖНО:
Vue устанавливается внутри конкретного проекта. Не нужно выполнять npm install vue глобально для обычной разработки.

29. УСТАНОВКА FLUTTER

Официальная документация:
https://docs.flutter.dev/install

Для Windows можно установить Flutter SDK вручную или через VS Code. Официальная документация Flutter рекомендует вариант с VS Code как быстрый способ настройки.

Вариант установки через VS Code:

1. Открыть VS Code.
2. Открыть Extensions.
3. Установить расширение Flutter.
4. При необходимости VS Code предложит установить Flutter SDK.
5. Выбрать папку для Flutter SDK.

При ручной установке Flutter SDK можно использовать папку:

C:\Users\<имя_пользователя>\develop

Не рекомендуется использовать путь с пробелами или специальными символами.

После распаковки Flutter добавить в PATH папку:

C:\Users\<имя_пользователя>\develop\flutter\bin

Открыть новые окна PowerShell/VS Code после изменения PATH.

Проверить:

flutter --version

Затем:

dart --version

Проверить установку и возможные проблемы:

flutter doctor -v

Официальная документация Flutter указывает, что Git и редактор/IDE являются предварительными компонентами, а команда flutter doctor используется для проверки среды.

30. FLUTTER: КАКОЙ ЦЕЛЕВОЙ ПЛАТФОРМЕ УЧИТЬСЯ

Если Flutter нужен только для разработки веб-приложений, сначала достаточно настроить Flutter Web.

Для Flutter Web нужен современный браузер. Дополнительная установка Android Studio для запуска Web не требуется.

Создать тестовый проект:

flutter create test_app

Перейти в него:

cd test_app

Запустить:

flutter run -d chrome

Если проект запустился в Chrome, Flutter Web настроен.

Для разработки Android-приложений потребуется дополнительная настройка Android SDK/Android Studio.

Для разработки Flutter-приложений под Windows потребуется Visual Studio с workload:

Desktop development with C++

Это отдельная программа от Visual Studio Code.

33. FLUTTER ДЛЯ ЭТОГО ЗАДАНИЯ

В предоставленном КИМ Flutter не указан.

Задание описывает разработку веб-приложения и веб-интерфейса, поэтому Flutter не является обязательным инструментом для выполнения именно этого КИМ.

Flutter можно установить для других учебных заданий, но специально для данного КИМ его установка не требуется.

34. PYTHON ДЛЯ ЭТОГО ЗАДАНИЯ

В предоставленном КИМ Python прямо не указан.

Python можно использовать в качестве языка серверной части, если выбрать соответствующий стек разработки, но КИМ не требует именно Python.

Если для этого задания выбрать Node.js + Vue, Python для проекта не понадобится.

Если же преподаватель отдельно требует Python или Python-фреймворк, тогда Python нужно установить дополнительно.
